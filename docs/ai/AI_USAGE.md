# AI usage

The project is intentionally AI-assisted because the Mad Devs assessment expects agent usage to be disclosed.

## Initial scaffold

- Tool: ChatGPT
- Model: GPT-5.6 Sol
- Role: architecture critique, scaffold generation, test/CI planning and documentation.
- Developer responsibility: scope approval, local execution, review, corrections, Git commits and final ownership of submitted code.

The operating rule is simple: AI output is not treated as evidence. Tests and reproducible runtime checks are evidence.
